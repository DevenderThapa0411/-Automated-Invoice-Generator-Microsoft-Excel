 # 📄 Automated Invoice Generator | Microsoft Excel

## 📌 Project Overview

This project is an automated invoice generator built in *Microsoft Excel*. It simplifies invoice creation by allowing users to select products from a drop-down list, automatically retrieving product prices and calculating invoice totals, GST, and Grand Total using Excel formulas.

The project demonstrates practical Excel skills used in business operations and billing automation.

- Minimize manual data entry.
- Reduce calculation errors.
- Improve billing efficiency.

## ✨ Key Features

- Product selection using drop-down menus.
- Automatic product price lookup.
- Quantity-based amount calculation.
- Automatic Total Amount calculation.
- Automatic SGST (9%) calculation.
- Automatic CGST (9%) calculation.
- Automatic Grand Total calculation.
- User-friendly invoice layout.
